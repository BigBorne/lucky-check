# Чек на удачу

Первый рабочий срез тестового проекта — регистрация аккаунта и авторизация.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/signup/`, создайте аккаунт. После входа откроется личный кабинет. Страница кабинета доступна только авторизованным пользователям.

## Уже сделано

- Регистрация пользователя со стандартными валидаторами Django.
- Вход и выход через `django.contrib.auth`.
- Защищённая страница кабинета.
- SQLite для первого локального среза; PostgreSQL подключим отдельным шагом.
