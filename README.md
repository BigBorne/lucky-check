# Stage 2

Сейчас готовы регистрация и вход пользователя, а приложение работает с PostgreSQL (перенес с SQLite) через docker-compose

## Запуск

1. Настройки .env:

   ```bash
   cp .env.example .env
   ```

2. Запуск:

   ```bash
   docker compose up --build
   ```

3. Открой `http://localhost:8000/signup/` и заргистрируй аккаунт

При первом запуске Django сам создаст таблицы для пользователей

## Что уже работает

- Регистрация, вход и выход через стандартные средства Django
- Страница кабинета открывается только после входа
- PostgreSQL запускается вместе с приложением

Настройки базы и сайта лежат в `.env`. Файл `.env.example` - пример: перед реальным использованием замени секретный ключ и пароль бд.
